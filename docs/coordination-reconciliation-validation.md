- 初回の限定試験ではActionの元Runtime/Generationを存在しないLedger列から取得していた。正規Dispatch Auditによる固定へ修正。
- Action適用時に不変Seed列までUPDATEした不具合を、変更列のみのUPDATEと元行全体のCASへ修正。
- 旧4B Transaction途中に未完成Receiptを現在投影から読んだ不具合を修正。完成済み履歴Readerの検証は維持。
- 封鎖Attemptの再送拒否より先にHoldが保存された問題を修正し、拒否の全表不変を追加確認。
- 初回の開発途中全体実行は1,643件中1,624 pass / 19 fail。旧Schema固定値、破損DB FixtureのSQL関数不足、DELETE TriggerのNEW参照、上記Action処理、移行Fixtureの未来形式Usageを修正。Assertionの緩和やSkip追加は行っていない。

最終の独立監査で、Verification期限切れ後の履歴保持（IN-08）と元Invocation期限後の新承認による精算（US-12）の直接試験不足を検出した。実時間の期限超過を用いる試験を追加した。また、Crash後の子Process照会を認証付きの候補・本文・Verification・Case・Plan/Operation Receipt読取へ強化し、存在しないReceiptや公開Grant Readerを照会したと誤読される記述を修正した。本番実装の変更は不要だった。
